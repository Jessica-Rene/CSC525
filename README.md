# ml5-boilerplate: with p5.js

A basic HTML, CSS, and JavaScript boilerplate for building a project with ml5.js and p5.js.

## Prerequisites
* [Visual Studio Code](https://code.visualstudio.com/)
* The **Live Server** extension installed in VS Code.

## How to Run
1. Open this project folder in Visual Studio Code.
2. Open the `index.html` file.
3. Right-click anywhere in `index.html` and select **Open with Live Server** (or click **Go Live** in the bottom-right status bar).
4. Your default web browser will automatically open the project locally.
